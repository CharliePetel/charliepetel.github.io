Generate Artists or Exhibitions
1. Have Nodes installed (https://nodejs.org/en/download)!

Add Artist
1. Add Artist in kuenstler.json
2. Right click and open with terminal
3. type: node generate-artists.js
4. click enter key
5. upload new Artist sub pages
6. upload the artist.html
7. upload the new kuenstler.json

Add Exhibition
1. Add Exhibition in Ausstellung.json
2. run: node generate-pages.js
